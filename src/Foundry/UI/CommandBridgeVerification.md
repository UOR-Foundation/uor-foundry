## Required completion boundary

An immutable SDK release must own this full source/kernel/native std/no_std/
Wasm/browser corpus and all representative mutations unconditionally. Its
closed input/output inventory, captured executable identities and before/after
guards must reject stale, substituted, skipped or incomplete evidence. Retained
host paths and compiler binaries must not become consumer CI dependencies.

The complete DK-26/DK-30 session owns live continuation, authenticated current
state, journaling and durable command consumption. Actual mailbox verification,
private saved-code recovery, domain service transitions, styled application
journeys, dispatch/replay and release/deployment verification remain required.
This component introduces no handwritten product coordinator to replace them.
